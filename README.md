HTML · CSS · JavaScript만으로 만든 정적 사이트라서 **GitHub Pages로 무료 배포**할 수 있습니다.

## 🚀 GitHub Pages로 배포하는 방법

### 1단계. 저장소 확인
이 파일들이 GitHub 저장소(`masters-english-homepage`)의 **main 브랜치**에 올라가 있으면 준비 끝입니다.

### 2단계. Pages 켜기
1. GitHub에서 저장소 페이지로 들어갑니다.
2. 위쪽 메뉴에서 **Settings(설정)** 를 누릅니다.
3. 왼쪽 메뉴에서 **Pages** 를 누릅니다.
4. **Build and deployment** 항목에서
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` 선택, 폴더는 `/ (root)` 선택
5. **Save(저장)** 를 누릅니다.

### 3단계. 1~2분 기다리기
잠시 후 같은 Pages 화면 위쪽에 아래와 같은 주소가 나타납니다.

```
https://<GitHub 아이디>.github.io/masters-english-homepage/
```

이 주소가 바로 홈페이지 주소입니다. 학부모님께 문자나 카카오톡으로 보내시면 됩니다.
(저장소 위쪽 **Actions** 탭에서 초록색 체크 표시가 뜨면 배포가 끝난 것입니다.)

### 4단계. 내용을 고친 뒤 다시 반영하기
main 브랜치에 수정한 파일을 올리면(커밋 · push) **자동으로 다시 배포**됩니다. 따로 할 일은 없습니다.

GitHub 웹사이트에서 바로 고치는 방법:
1. 저장소에서 `index.html` 을 누릅니다.
2. 오른쪽 위 **연필 아이콘(Edit)** 을 누릅니다.
3. 내용을 고친 뒤 **Commit changes** 를 누릅니다.
4. 1~2분 뒤 홈페이지에 반영됩니다. (휴대폰에서 바로 안 바뀌면 새로고침)

### (선택) 나만의 도메인 연결
`mastersenglish.co.kr` 같은 도메인을 구입했다면 **Settings → Pages → Custom domain** 에 입력하고,
도메인 업체 설정에서 GitHub가 안내하는 DNS 값을 넣으면 됩니다.

## ✏️ 개원 전에 채워 넣을 자리

`index.html` 에서 대괄호 `[ ]` 로 표시된 부분이 아직 비어 있는 자리입니다. 검색(Ctrl+F)으로 `[` 를 찾아 바꿔 주세요.

- `[주소 미정 — 확정 후 안내 예정]` — 오시는 길의 주소
- `[주소 미정]` — 맨 아래(푸터)의 주소
- `[개원 일자]`, `[주차 안내]`
- `[등록번호]`, `[사업자번호]` — 학원 등록 후 기재
- `[ 원장 프로필 사진 ]`, `[ 지도 ]` — 회색 박스 자리

### 사진 넣는 방법
1. 저장소에 `images` 폴더를 만들고 사진(예: `director.jpg`)을 올립니다.
2. `index.html` 에서 아래 줄을 찾아
   ```html
   <div class="photo-ph" role="img" aria-label="원장 프로필 사진 자리">[ 원장 프로필 사진 ]</div>
   ```
   다음처럼 바꿉니다.
   ```html
   <img src="images/director.jpg" alt="이승태 원장" style="aspect-ratio:4/5; object-fit:cover; border-radius:24px; width:100%;">
   ```

### 지도 넣는 방법 (주소 확정 후)
네이버 지도 또는 카카오맵에서 학원 위치를 찾아 **공유 → 지도 퍼가기(HTML 태그 복사)** 를 누르고,
`[ 지도 ]` 회색 박스 부분을 복사한 코드로 바꾸면 됩니다.
